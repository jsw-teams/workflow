# 视频工作流

从任务选择路线：[动作库](actions/README.md)保存可引用的姿态；[有限动画](limited/README.md)复用素材并量测落脚；[整场景叙事](scene/README.md)组织接触状态和画外旁白；[花店试播](pilot/README.md)研究连续视频生成。

媒体统一见根目录 media.json。查看作品使用条目中的 share_url；重建图像素材使用 original_url 并校验 source_sha256。仓库不包含媒体文件，也不包含上传密钥。

已有两部历史有限动画成片与一条未完成接触的连续试播，能力范围分别记录。静态图编码成视频、媒体解码通过、参考图绑定、接触动作通过是不同结论，不能互相代替。详细过程与反例见 [HISTORY.md](HISTORY.md)。
