# 网页试播提示词

第一轮计划提示词见 `prompt-trial-01.txt`，第二轮只修正停步位置的提示见 `prompt-trial-02.txt`。第一轮实际网页提交的提示与附件没有记录，不能声称计划提示已被原样执行。

上传锁定母图，保持雨夜花店、人物与盆的位置；人物走到外露盆沿旁，略弯肘即可接触后才停步、蹲下，手落在陶器而非散落叶片上。本轮盆全程侧倒。首帧模式与多参考模式分开记录，不假定网页拥有 API 的全部输入能力。

后续剧情见 `STORY.md`。只有接触状态经实片审查通过，才可用该状态作为扶正镜头的起点；场景母图永不被覆盖。扶正、与店员致意、离开分别生成与验收，不将故事板或合成图当作视频帧。
