# 参考图优先级和版本规则

1. `scene_master_LOCKED.png` 为主场景事实来源（不可自动替换）：建筑、门窗、街道、光源、机位、花盆位置。
2. `character_reference_CROP.png` 与 `fallen_flowerpot_reference_CROP.png` 直接从主图裁切，只负责确认身份与外观，不证明新的动作与三维关系。
3. `last_approved_state.png` 可随镜头更新，但只有人工/视觉审查通过后才允许升级为下一次生成的前置状态；不能覆盖母图。
4. `candidate/` 为未经验证的新结果；`rejected/` 记录失败结果与失败理由；`approved/` 保存被审查认可的镜头状态。
5. 所有引用图在请求前计算 SHA-256。**哈希错误是构建错误**；参考图在视觉上相似却与主图不同，不得静默覆盖。
6. 如模型不支持三张参考图片，按实际接口选择首帧或多参考模式，把模式及参与图片写入每次试验记录，不虚称所有参考已生效。
7. 主画面并非要求背景像素不变：合理的摄像机平移、透视和视差可以接受；但门/窗/灯/排水沟的空间逻辑与人物移动方向不能互相矛盾。
