# Codex 审核标准（先校验再接受）

Codex 扮演**可复核的审片与修复协调者**，而非“生成通过”的默认打分机器。Codex 可以执行脚本、逐帧抽图、检查参考和比对镜头状态，但仅凭传统程序无法自动证明手真正握住物体、遮挡关系物理合理或故事动人。

## 证据分级

- **A 程序可严格验证（P0 阻断）**：输入母图哈希、视频解码、视频流存在、分辨率/帧率记录、明确时间线长度或读写错误、引用来源存在、输出文件可打开。
- **B 视觉自动提示（需要复核）**：静态/低运动候选段、画面跳变、参考图特征不匹配、人物/盆数疑似改变、遮挡掩膜交叠、脚部接触可疑。任何自动模型/视觉检测可能误报，不能仅以数字决定通过。
- **C 视觉与叙事人工验收（P0 或 P1）**：花盆移动前是否接触、是否多出陶盆/人物、运动路线是否合理、门窗方位是否漂移、遮挡是否前后正确、叙事事件是否已经完成、是否有无目的的拖尾。

## 最低镜头验收表

| 字段 | 通过标准 | 缺陷级别 |
| --- | --- | --- |
| prompt_type | 输出真实连续镜头，不是海报/拼图/图表 | P0 |
| reference_binding | 实际调用明确包含正确的锁定主图；哈希一致 | P0 |
| scene_geography | 门、窗、街道、排水沟的空间逻辑不漂移 | P0 |
| character_identity | 人物外观、鞋、斜挎包保持一致 | P1/P0（重大） |
| prop_inventory | 始终只有一只陶盆，位置和状态连贯 | P0 |
| action_causality | 先触碰再移动，不能凭空立起 | P0 |
| hand_occlusion | 手不穿透盆沿，遮挡符合实际前后顺序 | P0 |
| foot_support | 双脚落在可以承重的人行道上 | P0 |
| camera_axis | 本镜人物行动方向一致，不无故翻轴 | P1/P0（严重） |
| narrative_progress | 发生目标事件；事件完成后剪掉无用的空白 | P1 |
| edit_transition | 相邻镜头动作、视线/声音有明确承接 | P1 |

## 不设置固定时长的结束规则

- 生成输出时长是模型的技术参数，不是故事规定。**实际剪辑在当前事件可视表达完成时结束**。
- 完成“发现花盆”不代表已经“扶起花盆”；不能借剪辑跳过必需接触状态。
- 镜头事件完成后，如果画面仍持续但无新动作、反应、构图或氛围信息，标记 `dead_tail`，提示裁剪。
- 对故意保留的宁静氛围，需要 `hold_purpose` 明确理由，避免将所有静止一概判为无效。
- 对尾部采用观众可观察事件 `completion_condition` 定义，不提前承诺 2/4/8 秒。

## 修复策略

- `prompt_type` 错误：重选生成模式或输出约束；不得按有效镜头计。
- `scene_geography` 错误：回到母图，变更机位前明确锚点；必要时使用草图/深度/3D 结构。
- `action_causality` 错误：退回最近一个通过的状态，拆为靠近、触碰、握住、移动、释放。
- `hand_occlusion` 错误：局部近景、Mask 或重设摄影机；不能用“遮住缺陷”代替证明。
- `narrative_progress` 错误：缩短成片使用长度、增加有效新事件，而不是生成无意义假动作。

## Codex 审片任务 Prompt（复制给 Codex）

```
你是 AI 短片项目的质量审查与修复协调者，不是自动赞美者。
读取 shot_contract.json、REFERENCE_POLICY.md 和 references/ 下的图片。
对于给定生成视频：
1. 运行 python qa_media.py --video <文件> --contract shot_contract.json --out <目录>。
2. 逐张检查输出 contact_sheet.png 与原图（重点：第一次接触前、接触时、镜头末尾）。
3. 对 CODEX_QA_STANDARD.md 的每项标准输出 pass / fail / unverified，并对 fail 给出明确证据帧和观察到的事实。
4. 区分 `技术校验通过` 与 `叙事/接触通过`。未能观察、无法获取原模型输入时一律 unverified，不猜测。
5. 若有 P0 则 REJECT；若无 P0 但还有 unverified 则 NEEDS_REVIEW；只有 P0/P1 全部明确通过才 APPROVE。
6. 给出最小修复策略：修提示词 / 恢复主参考 / 拆动作 / 改景别 / 删除拖尾 / 拒绝该镜头。
7. **禁止把固定视频输出时长反推成剧情时长**。镜头结束由可观察事件决定。
最终输出质量报告、失败证据以及下一次生成 Prompt 的变化点。
```

## 声明

`qa_media.py` 只做媒体检查、锁定参考哈希和静止候选定位；不会自动识别所有语义事件，也不调用 Veo/ImageGen。Codex 或人工必须填报视觉审核项。没有语义审核的报告结论只能是 NEEDS_REVIEW 或 REJECT。
