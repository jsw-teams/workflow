# Asset provenance

Project illustrations and the action-sheet example were generated with ImageGen. The selected story frames are exact saved generated pixels; hashes and native dimensions are stored in the project manifests. Their use here is authorized by the project operator. No native 1080p or model-seed reproducibility is claimed.

The motion example contains an original fictional character. Its pose sequence is an experiment, not a seamless or anatomically verified motion cycle. The contact benchmark uses a generated setting and character texture, with deterministic 2D deformation used only for its control experiment.

The Taipei official garbage-bag reference used during production is not redistributed. The fictional film does not validate official bag printing, a real collection route or a scheduled stopping time.

Code is licensed under MIT. The operator makes original generated project illustrations and original procedural audio available under the same project license, to the extent the operator may grant those rights. Microsoft synthesized speech and third-party tools remain subject to their applicable terms. No exclusive copyright or ownership over model-generated content is asserted.

The retained 150-second Rainy Delivery film is an accepted earlier limited-animation example from this project. Its source hash and current decode checks are saved in `limited/examples/rainy-delivery/verification.json`. It combines generated illustrations, layered poses, procedural audio and historical Windows local Hanhan narration. It has not been resynthesized with the newer REST narration path. Only the completed film and captions are retained here; its old full production project is not part of the public rebuild contract.

Images and video are external ishare resources listed in root media.json. Original image bytes retain their hashes; hosted video playback is transcoded and does not reproduce the uploaded video hash. Narration MP3 and soundtrack WAV are no longer local distributed assets. Narration text, requests, historical hashes and procedural mixing code remain; rebuilds regenerate speech online and update the local manifest.

The flower-shop storyboard was supplied by the operator as a narrative reference; its generating tool was not verified. The continuous pilot was supplied from Gemini web, with model name reported by the operator. Neither is claimed as a new ImageGen output from this workflow.
