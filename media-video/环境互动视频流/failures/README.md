# 需要人工审看的失败类型

精选能力证据与正式 frames 隔离，不发布完整私人执行日志。见 [catalog.json](catalog.json)。

- [人物与护栏深度](guardrail-depth.png)：身体／踏面与栏杆遮挡关系不可靠。改用无前景护栏近景，原能力暂缓。
- [楼梯空间漂移](stair-geography.png)：平台与阶梯轴线重解读。完整场景参考能帮助，但不保证成功。
- [物品重复](duplicate-can.png)：地上的罐子尚未拿起，袋口却出现另一罐。检查完整库存，再选择或重做。
- [水窪与方向](road-puddle.png)：人物方向和人行路面失配。用地面接触近景继续叙事，不能把车道边画面当成安全路线。

标签描述本次观察，不构成模型通用失败率。未选择的旧作品、私有聊天和机器路径不作为兼容接口。
