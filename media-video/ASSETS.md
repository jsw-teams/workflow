# Asset provenance

Project illustrations and the action-sheet example were generated with ImageGen. The selected story frames are exact saved generated pixels; hashes and native dimensions are stored in the project manifests. Their use here is authorized by the project operator. No native 1080p or model-seed reproducibility is claimed.

The motion example contains an original fictional character. Its pose sequence is an experiment, not a seamless or anatomically verified motion cycle. The contact benchmark uses a generated setting and character texture, with deterministic 2D deformation used only for its control experiment.

The Taipei official garbage-bag reference used during production is not redistributed. The fictional film does not validate official bag printing, a real collection route or a scheduled stopping time.

Microsoft synthesized speech and third-party tools remain subject to their applicable terms. No exclusive copyright or ownership over model-generated content is asserted.

The retained 150-second Rainy Delivery film is an accepted earlier limited-animation example from this project. Its source hash and current decode checks are saved in `有限动画与低成本静态视频流/examples/rainy-delivery/verification.json`. It combines generated illustrations, layered poses, procedural audio and historical Windows local Hanhan narration. It has not been resynthesized with the newer REST narration path. Only the completed film and captions are retained here; its old full production project is not part of the public rebuild contract.
