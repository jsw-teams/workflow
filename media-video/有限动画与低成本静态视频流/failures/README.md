# 绕行动作变成翻越护栏的早期反例

[查看八秒诊断片](detour-barrier.mp4) · [来源与标签](catalog.json)

这段来自更早的整场景关键姿态重做尝试，末段自由手伸向并扶住护栏，腿部抬起靠近障碍，使指定的“无接触绕行”读成翻越护栏。它违反动作意图与路线约束；不能仅归为动作不够流畅或互动较弱。

诊断片由七个保持播放的姿态组成，包含循环与收势停留。八秒是播放时长，不是完整八秒连续动作。后来通过验收的《雨夜送药》150 秒二维骨骼版本使用了另一种制作办法，两者分开记录。

本反例保留原错误，没有修补成通过图。它提示：提示词里的“绕过障碍”必须有明确端点、开放路线与全程不触栏的手脚关系；生成后还要审看实际路线，检查人物是否翻越、穿栏或走到栏外。落脚量测与手部包围盒不相交，都不能独立证明人与场景的三维关系正确。

低成本方案限定低互动镜头，环境互动方案探索整场景接触，同时限制复杂遮挡。这个记录不是整场景生成已经普遍解决护栏的证据。详见 [历史复盘](../../HISTORY.md)。
