# 有限动画与低成本静态视频流

这条路线减少需要重新生成的画面：复用静态场景、人物姿态或少量人物纹理，用停留、切接和有限二维动作组织视频。它已完成《雨夜送药》150 秒测试成片，并通过有限动画成片验收；主要局限是人物与场景互动不足。后续探索整场景环境互动，正是为了补足这一点。

它适合说明视频、旁白故事、远景和低互动过场。[动作库](../动图与动作库制作/README.md)管理人物 ID、姿态与循环；本模块组织低互动镜头与量测；[环境互动流程](../环境互动视频流/README.md)探索拾瓶、放回、交付等人物与场景的接触事件。三条路线分别承担不同工作。

## 两种有限动画做法

**静态叙事图加剪辑。** 一张完整场景承载一句或一小段旁白，通过停留、细小推近和切到下一场景推进故事。人物与环境的关系已经画在图内；镜头运动改变观看位置，没有新的姿态时，不用运镜宣称人物完成了动作。

**静态背景加有限人物动作。** 保留背景，使用经过审看的透明姿态，或对已有纹理做有限二维变形。选择开放地面、清楚机位与小幅动作。人物比例、光线、鞋底高度和道具状态另行匹配；程序没有取得场景的真实三维结构。

两种做法可在同片混用。《雨夜送药》多数镜头为静态插画叙事，74–84 秒使用二维骨骼纹理动作。候车到车内、进门到交付用切镜表达。它完成了故事与有限动作目标，但这些切镜没有展示连续环境接触。

当前 `benchmark.py` 展示第二种中的二维纹理变形与支撑脚约束，属于独立控制实验。完整人体关节、任意服装和自动遮挡还没有通用实现。

## 镜头选择

|需求|可尝试的做法|验收重点|
|---|---|---|
|听到消息、看向窗外|完整静态图＋旁白，或少量头部姿态切接|视线目标清楚，身份延续|
|开放空地站立、示意|透明姿态复用，轻微重心变化|鞋底支撑、比例、光线和轮廓边缘|
|远景短步或简单过场|少量姿态／有限纹理变形|支撑与换脚可读，路线在可行走区域内|
|走到栏杆后方、绕复杂家具|先换开放构图，需要接触时切换整场景路线|不能用平移推测遮挡和深度|
|拾取、交接、坐下、跨台阶|整场景生成并拆分接触事件|接触状态、支撑面、物件库存|

同一街区可以切换门口、人行道或店外空地；不必让全片复用一张背景。复用发生在适合复用的镜头内，不能为保持背景而把人物放到护栏外、车道上或没有落脚处的空间。

## 从分镜到输出

1. **定义叙事状态。** 写清这一镜头让观众知道什么，起点和终点是什么。例：角色在平坦候车区停下，远处车辆停靠。本镜不包含跨栏、登车或交付。
2. **判断互动需求。** 标出地面路线、前景物和目标方向。触碰、跨高度、被遮挡的段落，先改机位或分给环境互动流程。
3. **审看场景母图。** 地平线、地面、比例、光源与开放路线要成立。背景异常先修背景，不用人物平移掩盖空间问题。
4. **选择角色姿态。** 引用动作库中相同人物 ID、服装和道具状态的素材。保留完整人物和鞋底；记录多格裁切后真实尺寸。
5. **放置与匹配。** 校准比例、光线、鞋底高度与简单接触影子。单独检查透明边缘。本基准先预乘 alpha 再变形合成，减少色边；尚无任意素材自动抠图流程。
6. **安排有限动作。** 标明保持、移动、换脚与收势。全身移动不能让支撑鞋底一起滑动；没有足够姿态时缩短动作、停留或切镜。
7. **配旁白与声音。** 测实际语音长度后安排停留。字幕跟旁白，不暗示画中人物在说话。声音节奏服从画面与故事情绪。
8. **审看与编码。** 检查图层和物件，再看完整播放。解码、时长、哈希是技术检查；路线、动作和观感分别判断。

以上是制作步骤。公开脚本当前实现动作基准和量测，没有自动生成整支旁白故事的命令。可直接使用的提示模板见 [PROMPTING.md](PROMPTING.md)。

## 成本节省在哪里

复用减少的是背景和已验收角色素材的重复生成。镜头新增素材可按“新场景＋新姿态＋重试”登记；已有素材只记录引用。编码为 24fps 不要求每秒调用 24 次图像模型，也不代表每秒有 24 个新姿态。

整场景方案每个新姿态都可能重新画背景、角色与道具；分层方案保留背景，只补必要姿态。但它增加切图、绑定、比例匹配、合成和人工检查。如果接触复杂，这些返工会抵消生成节省，应换路线。

|成本项|可复用的部分|仍需投入|
|---|---|---|
|场景图|同镜头内的背景|新地点、新机位与背景修订|
|人物素材|已审看的相同造型与动作|新姿态、服装、视角和道具状态|
|合成|已有路线与参数|比例、光线、边缘和落脚适配|
|音画剪辑|模板、已测语音、字幕流程|故事节奏、混音、完整审看|

建议每镜登记调用次数、选用姿态、重试原因、复用来源、切图／合成时间和审看时间，取得实际账单后才填费用。本项目没有图像账单，不能给省钱百分比；十秒动作基准与 160 秒故事也不是同任务成本对照。

## 当前支撑脚量测

同一纹理、背景和路线分别保留或取消支撑脚约束。双腿通过二维两段骨架计算落点，超出可达范围会夹限并记录。取消约束版在名义支撑期间仍让鞋底随人物前移，作为滑移对照。

量测读取真实 H.264 解码图，用 21×11 鞋底纹理模板，在 0.25 秒窗口匹配，相关系数至少 0.8。程序坐标限定搜索范围，位移来自匹配像素。跨换脚周期、鞋互相遮挡与匹配不足的窗口排除。

|条件|合格窗口|中位位移|95 分位|
|---|---:|---:|---:|
|固定落脚|27|0px|3px|
|取消约束|18|20px|约 21px|

[逐窗口数据](evidence/measurements.json)保留相关系数和匹配位置。窗口来自同一短片、可能重叠，数量不同，没有严格配对、独立样本或统计显著性结论。这验证本基准可见支撑脚滑移，不能单独证明完整步态、隐藏脚、三维受力或人与背景交互自然。成片通过验收与这些技术边界可以同时成立。

## 从仓库根目录重跑

安装 `media-video/requirements.txt`，准备 FFmpeg／FFprobe。

```sh
# 量测现有证据，不生成新图、不联网合成语音
python "media-video/有限动画与低成本静态视频流/measure.py" --evidence "media-video/有限动画与低成本静态视频流/evidence"

# 从两张保存素材重建动作对照的两个分片
python "media-video/有限动画与低成本静态视频流/benchmark.py"
python "media-video/有限动画与低成本静态视频流/measure.py" --evidence "media-video/有限动画与低成本静态视频流/output"
```

`benchmark.py` 输出 `grounded.mp4`、`control.mp4` 和 `timeline.json`；现存 `evidence/comparison.mp4` 是并排展示，脚本不自动重拼它。`examples/rainy-delivery/` 是保存成片，不属于以上命令输出。

## 为什么继续保留

它为低互动镜头提供素材复用方法与动作验收工具，避免每个故事重新开发合成与量测。后续引用共享的[原创人物结构](../characters/original/README.md)，增加站立、转头和短步素材，再测试不同服装、机位的复用。

互动不足是探索第三条路线的理由。两条路线按镜头任务选择：低成本方案已完成有限动画目标，整场景方案继续测试接触、状态变化与环境关系。历史错误与后来通过的结果分开记录，见 [HISTORY.md](../HISTORY.md)。
