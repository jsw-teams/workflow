# 有限动画与低成本静态视频流

保留这个方向的理由，是它提供另一种成本取舍：无需每次重画整张场景，可复用静态背景和少量人物纹理，靠有限动作与剪辑形成视频。它适合介绍、说明、远景人物或低互动场面；人物与环境接触的真实感不足，因此必须在提示词阶段限制互动，见 [提示词与适用范围](PROMPTING.md)。

此模块保留支撑脚量测作为独立验收工具，不再保存第二套完整故事。动作库管理可用素材，环境互动流程用于拾取、交付等需要因果接触的叙事。两条路线根据镜头需要选择。

当前基准是同一纹理与路线的 10 秒二维骨骼对照。固定落脚与取消落脚约束分别编码后，以 21×11 鞋底模板、0.25 秒窗口、至少 0.8 相关系数量测可见支撑脚位移。

|条件|合格窗口|中位位移|95 分位|
|---|---:|---:|---:|
|固定落脚|27|0px|3px|
|取消约束|18|20px|21px|

骨骼与背景控制只用于这个基准，故事示例仍是整张图像生成。窗口数量不同，没有严格配对或统计显著性结论。二维支撑脚位移小也不证明整体步态自然，更不证明三维接触正确。

未来用于比较新的动作库版本与生成策略：鞋底落点、握持前后的物件状态、人物与遮挡物深度顺序。算法自动量测与人的画面审看分开报告。这样，素材和故事可以变化，验收方法仍可重用。
