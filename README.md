# Workflow

可检查、可重建的 AI 辅助工作流。每类工作流放在独立目录，仓库根目录保留给共用说明与未来扩展。

当前方向：[media-video](media-video/README.md)，包括动图与动作库、低成本有限动画、受限环境互动叙事。完整示例为 [《垃圾車來了！》160 秒旁白字幕版](media-video/环境互动视频流/examples/garbage-truck/film.mp4)。

项目从当前整理版本开始，不保留旧交接状态与旧版兼容接口。局限与必要对照证据跟随各模块；私人执行记录、机器路径和令牌不发布。

代码采用 [MIT](LICENSE)。视频相关素材与第三方说明分别见 [素材来源](media-video/ASSETS.md) 和 [第三方归属](media-video/THIRD_PARTY.md)。
